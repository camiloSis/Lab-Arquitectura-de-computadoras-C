\section{Marco Teórico}

Una computadora es un dispositivo electrónico compuesto principalmente por un \textbf{procesador}, \textbf{memoria} y \textbf{dispositivos de entrada y salida}. Una de sus principales características es la capacidad de ejecutar diferentes tareas dependiendo del programa que se encuentre cargado en su memoria.

\subsection{Procesador}

El procesador es considerado el ``cerebro'' de la computadora. Es un circuito integrado compuesto por una gran cantidad de transistores que se encarga de realizar cálculos, procesar instrucciones y controlar el funcionamiento general del sistema. Entre sus principales componentes lógicos se encuentran la Unidad Aritmético-Lógica (ALU), los registros, la unidad de control y la memoria caché. Un ejemplo de fabricante de procesadores es \textbf{Intel}.

\subsection{Memorias}

Las memorias permiten almacenar temporal o permanentemente información necesaria para el funcionamiento del computador. Se pueden clasificar en diferentes tipos según su función, velocidad, capacidad y forma de almacenamiento.

\subsubsection{Memoria Principal}

La memoria principal comprende diferentes tecnologías utilizadas para almacenar información directamente relacionada con el funcionamiento del sistema.

\paragraph{ROM (Read Only Memory)}

La ROM es una memoria de solo lectura y no volátil, lo que significa que conserva la información almacenada incluso cuando el computador se encuentra apagado. Se utiliza, entre otras funciones, para almacenar el BIOS y la información necesaria para iniciar el sistema.

Entre sus principales variantes se encuentran:

\begin{itemize}
\item \textbf{PROM:} puede ser programada una sola vez mediante un dispositivo especial.
\item \textbf{EPROM:} puede borrarse mediante luz ultravioleta y posteriormente ser reprogramada.
\item \textbf{Flash/EEPROM:} puede borrarse y reescribirse eléctricamente sin necesidad de retirar físicamente la memoria del equipo.
\end{itemize}

\paragraph{RAM (Random Access Memory)}

La RAM es una memoria volátil utilizada para almacenar temporalmente los datos y programas que están siendo utilizados por el sistema. Su contenido se pierde cuando se interrumpe el suministro de energía.

La RAM puede clasificarse en:

\begin{itemize}
\item \textbf{RAM estática (SRAM):} mantiene los datos mientras exista suministro de energía.
\item \textbf{RAM dinámica (DRAM):} requiere un proceso de refresco constante para conservar la información almacenada.
\end{itemize}

Las memorias RAM pueden organizarse mediante diferentes tipos de módulos, entre ellos los \textbf{SIMM}, con 30 o 72 contactos, y los \textbf{DIMM}, con 168 contactos.

\paragraph{Tipos de DRAM}

La DRAM constituye una tecnología de memoria principal que se caracteriza por su bajo costo y por requerir un proceso periódico de refresco. Entre sus principales variantes se encuentran:

\begin{itemize}
\item \textbf{FPM:} una de las primeras tecnologías DRAM, con tiempos de acceso de hasta 60 ns. Fue utilizada en sistemas con procesadores 386, 486 y Pentium.

\item \textbf{EDO:} permite mover bloques completos de datos en lugar de limitarse a transferir un solo byte, alcanzando tiempos de acceso de hasta 45 ns.

\item \textbf{BEDO:} incorpora transferencias en ráfaga, reduciendo los tiempos de espera durante el acceso a los datos.

\item \textbf{SDRAM:} memoria sincronizada con la señal de reloj del procesador, lo que permitió mejorar considerablemente el rendimiento de los sistemas de su época.

\item \textbf{PC-100 / PC-133:} variantes de SDRAM certificadas para funcionar con buses de 100 MHz y 133 MHz, respectivamente.

\item \textbf{DDR SDRAM:} permite realizar transferencias en ambos extremos del ciclo de reloj, aumentando el rendimiento de transferencia de datos.

\item \textbf{ESDRAM:} incorpora una pequeña cantidad de memoria estática interna para acelerar los accesos a la información.

\item \textbf{DRDRAM:} tecnología de 64 bits que alcanzó velocidades de hasta 800 MHz y fue desarrollada, entre otros usos, para sistemas relacionados con tarjetas gráficas AGP.

\item \textbf{SLDRAM:} tecnología basada en un protocolo abierto que buscaba alcanzar velocidades superiores a 800 MHz.

\end{itemize}

\paragraph{SRAM (Static RAM)}

La SRAM es una memoria más rápida que la DRAM, aunque presenta un costo de fabricación superior. Debido a sus características, se utiliza principalmente en sistemas de memoria caché.

Entre sus tipos se encuentran:

\begin{itemize}
\item \textbf{Async SRAM:} memoria asíncrona considerada una de las tecnologías más antiguas, con tiempos de acceso aproximados de 20 a 12 ns.

\item \textbf{Sync SRAM:} memoria sincronizada con el procesador, con tiempos de acceso aproximados de 12 a 8.5 ns.

\item \textbf{Pipelined SRAM:} presenta una carga inicial ligeramente más lenta, pero permite realizar accesos posteriores con mayor rapidez, alcanzando tiempos aproximados de 8 a 4.5 ns.

\end{itemize}

\paragraph{Tag RAM}

La Tag RAM almacena las direcciones asociadas con los datos que se encuentran en la memoria caché. Esto permite determinar rápidamente si un dato solicitado por el procesador se encuentra disponible en la caché.

\paragraph{VRAM}

La VRAM es una memoria especializada utilizada en las tarjetas gráficas. Su diseño permite que el procesador pueda escribir información mientras el monitor realiza la lectura de los datos necesarios para representar las imágenes.

\paragraph{Memoria Caché}

La memoria caché funciona como un nivel intermedio entre el procesador y la memoria RAM. Su objetivo es almacenar temporalmente los datos e instrucciones utilizados con mayor frecuencia, reduciendo el tiempo necesario para acceder a ellos.

Entre sus principales niveles se encuentran:

\begin{itemize}
\item \textbf{L1:} se encuentra integrada en el procesador. Es muy rápida, aunque posee una capacidad relativamente pequeña, aproximadamente entre 32 y 64 KB.

\item \textbf{L2:} se encuentra entre el procesador y la memoria RAM. Posee una capacidad superior a la L1, aproximadamente entre 256 KB y 1 MB.

\end{itemize}

\paragraph{Memoria Secundaria}

La memoria secundaria corresponde a los dispositivos destinados al almacenamiento masivo y permanente de información. A diferencia de la memoria RAM, conserva los datos incluso cuando el equipo se encuentra apagado.

Algunos ejemplos son los discos compactos (CD), DVD, discos duros, cintas magnéticas, memorias flash y unidades de estado sólido (SSD).

\subsection{Bus}

El bus es el conjunto de líneas de comunicación que permite transportar información entre los diferentes componentes de un computador. Puede considerarse como una serie de ``autopistas'' por las que circulan datos, direcciones y señales de control.

Los principales tipos de bus son:

\begin{itemize}
\item \textbf{Bus de Datos:} transporta la información entre los diferentes dispositivos del sistema, como el teclado, la pantalla, los discos y otros componentes.

\item \textbf{Bus de Direcciones:} indica la ubicación de memoria en la que se debe almacenar o desde la cual se debe leer determinada información.

\item \textbf{Bus de Control:} transporta las señales necesarias para controlar y coordinar las operaciones realizadas por los diferentes componentes.

\end{itemize}

En una placa ATX típica pueden encontrarse 64 líneas destinadas al transporte de datos y 32 líneas destinadas a direcciones. Esta configuración permite direccionar más de cuatro mil millones de posiciones de memoria.

\subsection{Entrada/Salida}

La entrada y salida (E/S) comprende los mecanismos mediante los cuales el computador se comunica con el mundo exterior utilizando diferentes dispositivos periféricos, como teclados, impresoras, monitores y dispositivos de almacenamiento.

La \textbf{Unidad de Entrada/Salida (E/S)} actúa como intermediaria entre los periféricos y el procesador. Su función consiste en gestionar las transferencias de información de acuerdo con las instrucciones proporcionadas por la Unidad de Control.

Entre los principales dispositivos periféricos se encuentran:

\begin{itemize}
\item \textbf{Monitor:} dispositivo utilizado para visualizar la información procesada por el computador. Puede clasificarse según su tamaño, expresado normalmente mediante la longitud de su diagonal en pulgadas, o según la tecnología utilizada.

\item \textbf{Mouse:} dispositivo de entrada utilizado para controlar el puntero y realizar diferentes acciones en la interfaz gráfica. Puede diferenciarse según su tipo de conexión, como serial, PS/2 o USB.

\item \textbf{Teclado:} dispositivo de entrada utilizado principalmente para introducir caracteres y comandos. Puede clasificarse según su tipo de conector, como AT, PS/2 o USB, y según sus características adicionales, como teclados multimedia, ergonómicos o inalámbricos.

\end{itemize}

\subsection{Glosario de términos técnicos}

\begin{itemize}
    \item \textbf{Chipset:} Conjunto de circuitos integrados en la placa madre que gestiona la comunicación entre CPU, memoria y periféricos. Características: incluye controlador de memoria, controlador PCIe y controladores de E/S; determina qué tipo de RAM y CPU soporta la placa.

    \item \textbf{Northbridge (Puente Norte):} Chip (histórico, hoy integrado al CPU en sistemas modernos) que conecta la CPU con la RAM y el bus gráfico de alta velocidad. Características: maneja el bus frontal (FSB) y el acceso a memoria a alta velocidad.

    \item \textbf{Southbridge (Puente Sur):} Chip que gestiona los dispositivos de E/S más lentos (USB, SATA, audio, red). Características: se comunica con el Northbridge y expone los buses PCI/PCIe secundarios.

    \item \textbf{BIOS/UEFI:} Firmware almacenado en memoria no volátil que inicializa el hardware al encender el equipo. Características: reside en memoria flash; UEFI soporta discos GPT y arranque en modo gráfico, a diferencia del BIOS clásico limitado a MBR.

    \item \textbf{PCI (Peripheral Component Interconnect):} Bus de interconexión de componentes periféricos usado para conectar tarjetas de expansión a la placa madre. Características: transferencia en paralelo, ancho de bus típico de 32/64 bits, velocidad hasta 133 MB/s.

    \item \textbf{PCIe (PCI Express):} Evolución serial del bus PCI, organizado en carriles (lanes). Características: cada lane (x1, x4, x8, x16) transmite datos en full-duplex; PCIe 4.0 alcanza hasta 16 GT/s por lane.

    \item \textbf{DIMM (Dual In-line Memory Module):} Módulo de memoria RAM con contactos independientes en cada cara. Características: 168 contactos (SDRAM) o más en DDR/DDR4/DDR5; se inserta en las ranuras de memoria de la placa madre.

    \item \textbf{SIMM (Single In-line Memory Module):} Módulo de memoria antiguo con contactos duplicados a ambos lados conectados eléctricamente entre sí. Características: 30 o 72 contactos, usado hasta la era del Pentium.

    \item \textbf{SATA (Serial ATA):} Interfaz de conexión para discos duros y unidades ópticas. Características: transferencia serial punto a punto; SATA III alcanza hasta 6 Gbps.

    \item \textbf{AHCI (Advanced Host Controller Interface):} Especificación que permite a los controladores SATA soportar funciones avanzadas como hot-swap y NCQ. Características: reemplaza el modo IDE heredado; mejora el rendimiento en accesos concurrentes al disco.

    \item \textbf{USB (Universal Serial Bus):} Bus estándar para conectar periféricos externos. Características: USB 2.0 hasta 480 Mbps, USB 3.0 hasta 5 Gbps, USB4 hasta 40 Gbps; soporta conexión en caliente (hot-plug).

    \item \textbf{ACPI (Advanced Configuration and Power Interface):} Estándar que permite al sistema operativo controlar la administración de energía y configuración del hardware. Características: gestiona estados de suspensión (S0-S5) y control térmico.

    \item \textbf{IRQ (Interrupt Request / Solicitud de Interrupción):} Señal que un dispositivo envía al procesador para solicitar atención inmediata. Características: cada dispositivo tiene asignado un número de IRQ; permite manejo asíncrono de eventos de E/S.

    \item \textbf{DMA (Direct Memory Access / Acceso Directo a Memoria):} Mecanismo que permite a los periféricos transferir datos hacia/desde la memoria sin intervención constante de la CPU. Características: libera ciclos de CPU; usado por tarjetas de sonido, red y almacenamiento.

    \item \textbf{Driver (Controlador de dispositivo):} Software que permite al sistema operativo comunicarse con un dispositivo de hardware específico. Características: opera en espacio de kernel o usuario; traduce llamadas del SO a comandos que el hardware entiende.

    \item \textbf{Firmware:} Software de bajo nivel embebido en un chip de memoria no volátil que controla el funcionamiento básico de un dispositivo. Características: normalmente en memoria Flash/EEPROM; actualizable mediante procesos de "flasheo".

    \item \textbf{Bus del sistema:} Conjunto de líneas eléctricas que transportan datos, direcciones y señales de control entre los componentes del computador. Características: se subdivide en bus de datos, bus de direcciones y bus de control.

    \item \textbf{Memoria caché (L1/L2/L3):} Memoria SRAM de alta velocidad ubicada entre el procesador y la RAM para reducir tiempos de acceso. Características: L1 dentro del núcleo (32-64 KB), L2 por núcleo o compartida (256 KB-1 MB), L3 compartida entre núcleos (varios MB).

    \item \textbf{VRAM (Video RAM):} Memoria dedicada de la tarjeta gráfica para almacenar datos de video/texturas. Características: accesible simultáneamente por GPU y para salida a pantalla; tipos comunes GDDR5/GDDR6.

    \item \textbf{Vendor ID / Device ID (Código PCI ID):} Identificadores hexadecimales únicos asignados a cada fabricante (Vendor ID) y modelo de dispositivo (Device ID). Características: formato \texttt{VEN\_XXXX\&DEV\_XXXX} en Windows o \texttt{XXXX:XXXX} en Linux (\texttt{lspci -nn}); permite identificar el driver correcto.
\end{itemize}

\section{Cuestionario}

\begin{enumerate}

    \item \textbf{Modelos de arquitecturas de computadoras}

    \begin{itemize}
        \item \textbf{Arquitectura de Von Neumann:} Se caracteriza por utilizar un espacio de memoria unificado para almacenar tanto las instrucciones del programa como los datos. Utiliza un único bus de datos y direcciones, lo que significa que la CPU no puede leer una instrucción y leer/escribir datos simultáneamente. Esto genera el conocido ``cuello de botella de Von Neumann'', pero es un diseño más simple y económico, base de la mayoría de computadoras modernas de propósito general.

        \item \textbf{Arquitectura Harvard:} A diferencia del modelo anterior, separa físicamente la memoria y los buses para los datos y las instrucciones. Esto permite a la CPU acceder a ambos simultáneamente, eliminando el cuello de botella y mejorando drásticamente el rendimiento. Aunque es más costosa y compleja, se utiliza extensamente en microcontroladores, procesadores de señales digitales (DSP) y en el diseño interno de la memoria caché de las CPUs modernas (arquitectura Harvard modificada).
    \end{itemize}


    \item \textbf{Principales sistemas de unidad de procesamiento (CPU)}

    \begin{itemize}
        \item \textbf{Intel (Arquitectura Core/x86):} Emplea un diseño híbrido que combina núcleos de rendimiento (P-cores) para tareas intensivas y núcleos de eficiencia (E-cores) para procesos en segundo plano. Destaca por su alta frecuencia de reloj, compatibilidad con tecnologías como Thunderbolt y optimización profunda con Windows.

        \item \textbf{AMD (Arquitectura Zen/x86):} Utiliza un diseño basado en \textit{chiplets}, lo que permite alta escalabilidad y menor costo de fabricación. Sus procesadores de gama alta incluyen la tecnología 3D V-Cache (memoria apilada verticalmente), lo que acelera masivamente el rendimiento en cargas de trabajo de baja latencia como los videojuegos y la simulación.

        \item \textbf{Apple (Arquitectura Apple Silicon/ARM):} Implementa sistemas en chip (SoC) donde la CPU, GPU y la memoria unificada están en la misma matriz. Su principal característica es la eficiencia térmica y energética líder en la industria, ofreciendo un alto rendimiento por vatio y una integración nativa de motores neuronales (Neural Engine) para inteligencia artificial.
    \end{itemize}


    \item \textbf{Principales sistemas de almacenamiento (Unidades de memoria/SSD)}

    \begin{itemize}
        \item \textbf{Samsung (Línea NVMe PCIe):} Sus unidades de estado sólido de gama alta utilizan tecnología V-NAND (3D NAND) de cientos de capas. Se caracterizan por sus controladores propios que minimizan el estrangulamiento térmico y alcanzan velocidades de lectura/escritura secuencial superiores a los 14,000 MB/s bajo el estándar PCIe 5.0.

        \item \textbf{Western Digital (WD Black):} Enfocados en el rendimiento sostenido para bases de datos y \textit{gaming}. Emplean memoria flash BiCS NAND, altos niveles de IOPS (operaciones de entrada/salida por segundo) y perfiles de firmware altamente agresivos apoyados por disipadores térmicos pasivos.

        \item \textbf{Micron (Crucial):} Pioneros en el desarrollo de chips NAND TLC de ultra alta densidad (más de 232 capas). Sus sistemas de almacenamiento integran soporte avanzado para Microsoft DirectStorage, permitiendo a la GPU acceder a los datos del SSD directamente sin saturar la CPU.
    \end{itemize}


    \item \textbf{Principales sistemas de Entrada/Salida (E/S)}

    \begin{itemize}
        \item \textbf{Intel (Controladores Thunderbolt):} Sus sistemas de E/S dominan la conectividad periférica de alta gama. La interfaz Thunderbolt ofrece un enorme ancho de banda (hasta 120 Gbps bidireccionales), permitiendo la conexión en cadena de monitores de ultra alta resolución, almacenamiento externo PCIe y suministro de energía bidireccional bajo un solo cable tipo C.

        \item \textbf{NVIDIA (Unidades de Procesamiento de Datos - DPU):} A través de su arquitectura Mellanox, desarrollan sistemas de E/S de red avanzados (SmartNICs). Descargan el procesamiento de red, almacenamiento y seguridad de la CPU central hacia un procesador dedicado en la tarjeta de red, manejando anchos de banda masivos (hasta 400 Gb/s) para centros de datos.

        \item \textbf{Logitech (Periféricos de usuario final):} Líder en la interfaz humano-computadora. Sus sistemas de E/S integran conectividad inalámbrica de latencia ultrabaja (tecnología Lightspeed), sensores ópticos de alta precisión que funcionan sobre cristal y sistemas de carga electromagnética continua en periféricos de entrada.
    \end{itemize}

    \item \textbf{Tendencias futuras en arquitectura de computadoras}

    \begin{itemize}
        \item \textbf{Computación Cuántica:} Reemplazo de los bits tradicionales (0 o 1) por \textit{qubits} que pueden existir en múltiples estados simultáneamente (superposición). Modificará drásticamente la arquitectura del hardware para realizar simulaciones moleculares, criptografía y análisis de sistemas complejos a velocidades inalcanzables para procesadores convencionales.

        \item \textbf{Computación Neuromórfica:} Arquitecturas de hardware inspiradas en el funcionamiento del cerebro humano, utilizando redes de neuronas artificiales a nivel de silicio (\textit{spiking neural networks}). Este modelo abandona la arquitectura tradicional para procesar información de forma paralela con un consumo de energía minúsculo, ideal para tareas de IA periférica e inferencia de datos.

        \item \textbf{Procesadores Específicos de Dominio (DSA) y Chiplets:} La Ley de Moore se ralentiza, por lo que las futuras arquitecturas dependerán menos de CPUs de propósito general y más de aceleradores dedicados (NPUs, DPUs, TPUs) empaquetados juntos en un formato de \textit{chiplet}. Esto permite mezclar y combinar diferentes tipos de procesamiento en un solo sustrato interconectado.

        \item \textbf{Fotónica de Silicio:} Sustitución de los tradicionales buses de datos de cobre por interconexiones ópticas. El uso de la luz para transferir datos entre la memoria y el procesador, o entre múltiples chips, eliminará la generación de calor limitante y multiplicará exponencialmente el ancho de banda, erradicando los cuellos de botella actuales de Entrada/Salida.
    \end{itemize}

\end{enumerate}

    \item \textbf{Sobre la Gestión de Versiones y Buenas Prácticas:} La implementación de Git y la estructuración del repositorio remoto en GitHub bajo un flujo de trabajo disciplinado (\textit{commits} descriptivos, control de ramas y asignación de colaboradores) garantizaron la trazabilidad, organización y seguridad del código fuente desarrollado a lo largo de la práctica.
\end{enumerate}
